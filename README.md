# README

## AGENTCOMPOSE

AgentCompose is an agent tool generator for your codebase, based on the style of shadcn.
Getting tool calls correct is a very difficult task, so AgentCompose ports standard tool implementations into your library to make that easier.

AgentCompose is enterprise first. Permissions and security are first-class citizens, ensuring that the data governance lifecycle remains intact.

### Features

- Control flow for agent tools
- Agent Orchestration
- Ability to make custom agent tool primitives

### USAGE

```bash

pip install agentcompose



```

```bash

agentcompose init
agentcompose add something

```
